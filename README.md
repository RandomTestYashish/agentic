# Agentic

Interactive prototype of a telco AI assistant in the new ember (reddish-brown) branding, built from the Figma file `Yashis-Imaginarium_22-jun` (node `81538:9546`).

**Live preview:** https://randomtestyashish.github.io/agentic/

- Home screen with the Agentic pill in the header
- First-time onboarding ("Welcome, Yashish!"), then the chat landing
- Chat with streaming replies, shimmer loaders, rich telco cards (usage, packs, plans, bill, network check, roaming, services), payments, feedback, read-aloud
- Voice mode with live transcript, mic-reactive orb and spoken replies

Plain HTML/CSS/JS, no build step. Add `?reset=1` to the URL to see onboarding again.
